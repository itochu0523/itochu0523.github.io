### 🚶 散歩メモ — 音声メモ × AI整理 × Suunto連携
**URL:** https://itochu0523.github.io/sanpo/sanpo-memo.html

散歩中にボタンを長押しするだけで音声をテキスト化。後でClaude AIがまとめ・カテゴリ分け・インサイト抽出・アクション化してくれる思考整理アプリ。SuuntoのワークアウトデータとAIメモを掛け合わせた「運動×思考」相関分析も可能。

| 機能 | 内容 |
|------|------|
| 🎤 音声録音 | ボタン長押しで即録音、自動テキスト変換 |
| 📝 メモ一覧 | タグ付き・フィルター付き全メモ管理 |
| 🤖 AI整理 | Claude APIで要約/カテゴリ/インサイト/アクション化 |
| 🏃 Suunto連携 | ワークアウトデータ取込・メモとの相関分析 |
| 💡 アイデアマップ | AI整理結果をカード形式で可視化 |

### ✅ Daily【TODOアプリ】曜日別タスク管理
**URL:** https://itochu0523.github.io/tasks/daily-tasks.html

一番よく使っている、毎日使うタスク管理アプリ。ダーク/ライトモード対応。

| 機能 | 内容 |
|------|------|
| 📅 曜日別・日曜始まり週タスク | 曜日ごとの毎日タスクと、日曜始まりでリセットされる週次タスクを管理 |
| ⚡ すぐやるタスク | その場で追加・削除できるクイックタスク |

| 💰 価格比較 | ネットスーパー等の価格を項目ごとに比較 |
| 📊 統計 | 達成率グラフ・履歴の可視化 |
| ☁️ クラウド同期 | JSONBin.io経由でMac/iPhone/iPad間同期 |
| 🌗 ダーク/ライトモード | 設定画面から切り替え可能（端末ローカル保存） |
